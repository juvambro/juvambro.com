A Tua Jornada Juvambro Etapa 2 de 9

Define

Transforma desejos vagos em algo concreto. Não precisas de saber tudo. Só precisas de decidir o que é mais importante para ti neste momento.

As tuas reflexões ficam guardadas no teu dispositivo

As tuas respostas são guardadas neste navegador e neste dispositivo. Não estão associadas a uma conta nem são sincronizadas entre dispositivos. Se limpares os dados guardados no navegador, poderás perder as tuas respostas. Se utilizares um dispositivo partilhado, evita introduzir informações sensíveis.

1

O que quero realmente?

Se pudesses melhorar uma área importante da tua vida, o que gostarias verdadeiramente que fosse diferente?

2

Porque é que isto é importante para mim?

Porque é que isto é importante? O que mudaria na tua vida se conseguisses alcançar esse objetivo?

3

Como seria o sucesso?

Imagina que conseguiste alcançar aquilo que desejas. Como seria a tua vida? Como te sentirias?

4

Qual é o meu principal objetivo neste momento?

Escolhe um objetivo que mereça a tua atenção. Não precisas de resolver tudo de uma só vez.

5

Que resultado quero alcançar primeiro?

Qual é um resultado importante que gostarias de alcançar com este objetivo?

A clareza dá-te uma direção.

Não precisas de ter todo o teu futuro planeado. Ter uma direção clara é suficiente para dares o próximo passo.

Escolhe o que é importante. Depois, continua a avançar.
